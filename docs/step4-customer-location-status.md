## 결정 (형우, 하나씩 확인)
| 항목 | 결정 |
|---|---|
| 자동 채움 | 입력하면 바로 제안. 명칭·분류·지역 → 소재지·기관 유형. 저장 전 확인·수정 |
| 보이는 분류 | 지방자치단체·의회만. 다른 분류에선 칸 숨김, 기존 값 유지 |

| 미입력 표시 | 고객사 상세 안내 + 고객사 관리 목록 배지 |
| 고객사 삭제 | 계약이 있어도 삭제 가능, 확인 화면 한 번. 관리자만 |

## 동작
- 제안은 `guess_location` 한 곳에서 계산(`/planning/location-guess/`, 관리자 전용 JSON).
- 소재지가 비어 있거나 제안으로 채운 값이면 명칭을 바꿀 때 다시 채운다. 직접 고른 값·저장된 값은 '명칭 기준 제안 [적용]'만 보여준다.
- 시·도를 고르면 그 시·도의 시군구만 보이고, 시군구 '(시·도 전체)'는 도청·광역 의회용.
- 삭제 범위: 고객사, 모든 계약(유효·종료)과 제품·설치 장소 연결, 통합된 중복 고객사, 이 계약에만 쓰인 설치 장소, 쓰이지 않게 된 기관·심볼. 다른 계약에도 쓰이는 장소·계약 상대 기관과 제품 목록은 남긴다.

## 고객사 등록·수정 화면 정리 (2026-10-22 형우 확정)
- 검토 후보: 실적 목록에 표시 / 총 고객사 수에 포함 / 표시 구분 / 지역. 형우 선택: 1번(실적 목록에 표시)만 빼고, 지역은 지자체·의회에서만.
- '실적 목록에 표시': 고객사 화면에서 뺌. 새 고객사는 표시로 저장, 이미 저장된 값은 그대로 둠(설치 장소 설정 화면에는 남아 있음). 중복 통합은 지금처럼 자동으로 끔.
- 지역(권역): 지자체·의회일 때만 보이고 소재지를 따라감(안내 "소재지를 고르면 자동으로 맞춰집니다."). 다른 분류에서는 칸이 숨고, 저장하면 지역 값을 비움(보이지 않는 값을 남기지 않음 — 카드의 '· 수도권' 꼬리도 사라짐).
- 그대로: 총 고객사 수에 포함, 표시 구분, 파트너사 공개 여부, 심볼, 참고 메모.
- 검사 추가: test_customer_location (목록 표시 칸 없음·저장값 유지, 지역은 지자체·의회만).

## 직접 계약한 소속 기관은 새 고객사로, 잘못 넣은 계약은 삭제, 심볼 빌려 쓰기 (2026-11-17 형우)
- 영천시 계약서 3건 검토: ①청소년문화의집·③청소년수련관은 발주처·수요기관이 영천시(가족행복과) → 영천시의 설치 장소. ②는 발주처·수요기관·기관관리번호가 모두 '영천시 환경사업소'(자체 재무관) → 별도 고객사, 계약 당사자도 환경사업소 자신. 시청·의회를 별도 고객사로 두는 원리와 같다(계약 기준).
- 처음엔 '설치 장소를 별도 고객사로 분리'하는 기능을 만들었으나, 형우: "그냥 새로 고객사를 추가하는게 나을 것 같은데? 제일 깔끔할 것 같은데?" → 분리 기능은 뺐다(_to_delete/site_split). 대신 잘못 넣은 계약을 지우는 **계약 삭제**(계약 상세 → '계약 삭제', 확인 화면): 계약 제품·설치 장소 연결을 지우고, 다른 계약에 안 쓰이는 설치 장소(표시 설정 포함)도 지운다. 중복 통합 기록과 묶인 계약은 지우지 않는다. '계약 종료'는 실제로 끝난 계약용(과거 기록 유지).
- 심볼 빌려 쓰기(`logo_fallbacks`): 심볼 없는 고객사는 계약 당사자 고객사의 심볼, 심볼 없는 설치 장소는 계약 고객사의 심볼(유효 계약 중 최근). 납품현황·인쇄·고객사 관리 목록 같게. 파트너사에게는 목록 표시·공개 고객사의 심볼만.
- 관리 화면 문구: '실적 목록 표시/미표시' → '납품현황 표시/미표시', '실적 집계' → '납품현황 집계'(실적 정보는 따로 없다).
