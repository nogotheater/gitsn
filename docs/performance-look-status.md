## 스크롤 중 검색·필터 (2026-10-22 형우 확정)
- 맨 위로 버튼 자리에 파란 알약 버튼 [🔍 | ↑] — PC·폰 공통. 흰색은 눈에 덜 띄어 브랜드 파랑으로(형우 결정).
- 🔍를 누르면 위쪽 띠 자리가 검색칸으로 바뀜(바로 입력, 폰 키보드에 가리지 않음). 입력하는 대로 0.3초 뒤 목록이 바뀜(새로고침 없음). 위쪽 검색창도 같은 방식.
- × 또는 Esc: 검색어 지우고 닫힘. 브라우저 기본 지우기(×)는 숨겨 ×가 하나만 보이게 함.
- PC 띠 왼쪽에 '필터' 버튼: 띠 아래 제품 칩 패널, 누르면 바로 적용되고 패널은 열린 채 유지. 결과가 짧아져 위쪽 칩이 다시 보이면 띠와 함께 닫힘.
- 필터 버튼과 목차 버튼은 한 장의 유리 띠 안에 구분선으로 나눔(사이 틈으로 뒤 내용이 비쳐 지저분해 보이던 것 정리).
- 폰은 필터를 하단 바에 그대로 두고 띠에는 넣지 않음.
- 검사 변경: 맨 위로 버튼 선택자를 알약 안 버튼으로, 띠 검색·띠 필터 동작 검사 추가.

### 보완 (2026-10-22 형우 확정)
- PC: 띠 한 줄에 [필터 | 🔍 기관명 검색 × | 지금 섹션·목차]. 알약의 🔍는 이 검색칸으로 커서를 옮긴다(위쪽 겹침 검색창은 폰만 씀).
- PC 띠 검색칸에 커서가 있는 동안은 결과가 짧아져 분류 칸이 다시 보여도 띠를 그대로 둔다(치던 칸이 사라지지 않게). Esc는 검색어를 지우고 칸을 빠져나온다.
- 깜박임 제거: 필터 칩을 누를 때 띠 전체를 새로 그리던 것을 멈추고, 바뀌는 부분(필터 숫자 배지·칩)만 바꾼다. 띠와 패널은 그대로 있다.
- 치고 있는 검색칸의 글자는 결과가 도착해도 덮어쓰지 않는다(빨리 칠 때 글자가 사라지지 않게).
- 폰: 🔍를 다시 누르거나 키보드를 내리면(완료·바깥 누름·키보드 내림) 검색창이 닫힌다. 걸러진 결과는 그대로 두고(위쪽 '검색 "…" ×' 칩으로 보임), 지우기는 ×.
- 검사: 띠가 같은 요소로 남는지(새로 그리지 않음), PC 띠 검색, 폰 🔍 다시 누름·키보드 내림·× 동작 추가.
- PC 띠 칸 구분(형우): 유리 띠 안에서 필터·검색·고객사 분류를 각각 흰 칸(둥금 6px, 사이 6px)으로 나눔. 검색칸은 조금 더 하얗고, 누르면 파란 테두리.
- 폰 알약: 진한 파랑은 누르는 동안만. 올렸을 때 진해지는 효과는 마우스가 있는 화면에서만(폰에서 누른 뒤 진한 색이 남던 것 해결).
- 검색 중 숫자(총 수·섹션 제목)는 지금처럼 전체 기준으로 둔다(형우 결정).
