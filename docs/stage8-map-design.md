# 8단계 지도형 보기 — 설계 결정 기록 (진행 중)

시작: 2026-10-20. PRD·지시문에서 "1차 제외"였던 지도형 보기를 추가한다. 결정은 한 항목씩 사용자 확인 후 기록한다. 구현은 설계가 끝난 뒤 시작한다.

## 확정된 결정

- **목적**: 영업 담당자가 한눈에 "우리나라 어느 지역에 제품이 납품됐고 어느 지역은 아직인지"를 알아보는 지도. 선거방송의 선거구 색칠처럼 직관적으로.
- **제품 묶음(분야)**: 도청 보안 = Alpha-S·Alpha-I·Alpha-P / 불법촬영 = Alpha-C·Alpha-EB(추가 예정). 지도는 제품 하나하나가 아니라 이 묶음 단위로 색을 칠한다. 묶음 소속은 제품 관리에서 지정할 수 있어야 한다(EB 추가 시 자동 반영).

- **지도 단위**: 시·군·구(약 230개)로 색칠하고 시·도 경계선을 굵게 겹쳐 그린다. 행정구역은 현행 기준으로 통일.

- **범위**: 지자체·지자체 의회만. 중앙정부·공공·교육 등은 지도에 올리지 않는다. 지자체와 의회는 따로 볼 수 있어야 한다(전환).
- **지방공기업**: 시트에서 지자체 분류 아래 들어 있는 지방공기업·출연기관(경기주택도시공사, 전남개발공사, 충청남도개발공사, 세종문화회관 등)은 행정기관과 구분해 별도로 표시한다. 고객사에 "기관 유형(행정기관 / 지방공기업·출연기관)" 구분이 필요하며, 지금 데이터에서 시·군·구 이름 규칙에 안 맞는 11곳이 후보다(목록 확인 예정).

## 데이터 현황 (2026-10-20)

- 지자체 133 + 의회 42 = 175곳 중 170곳은 이름에서 시·도를 읽을 수 있음. 5곳(서울동부 아동보호전문기관, 전남개발공사, 세종문화회관, 경기주택도시공사, 충청남도개발공사 등)은 소재지를 손으로 지정해야 함.
- 시트에 옛 이름(전라남도·전라북도·강원도)과 새 이름(전남광주통합특별시·전북특별자치도·강원특별자치도)이 섞여 있음 → 지도에서는 현행 행정구역으로 통일.
- 중앙정부·공공·금융·교육·민간·해외(329곳)는 소재지 정보가 없음.

3. ~~색 규칙~~ (확정: 한 지도에 도청 보안 파랑 · 불법촬영 빨강 · 둘 다 남색 · 없음 연회색. 상단에 전체/도청 보안/불법촬영 전환)

6. ~~인쇄·PDF~~ (확정: 2차. 1차는 웹 화면만)
7. ~~기획팀 입력~~ (확정)
   - 제품 관리: "분야"를 여러 개 지정(도청 보안 / 불법촬영 / 해킹 탐지 / 기타). P = 도청 보안 + 해킹 탐지. EB 추가 시 분야만 지정하면 지도에 반영.
   - 계약 입력: 분야가 둘 이상인 제품은 제품 줄에서 "용도"를 고른다. 기본값은 첫 분야. 지도 색은 이 용도 기준. 기존 데이터의 P는 모두 도청 보안으로 두고 아는 건부터 고친다.
   - 고객사 관리(지자체·의회): "소재지(시·도 → 시·군·구)"와 "기관 유형(행정기관 / 지방공기업·출연기관)"을 두고, 저장 시 이름에서 자동으로 채운다. 못 읽으면 비워 두고 기획팀이 고른다. 소재지가 빈 고객사는 지도에 안 나오고 "소재지 미지정 N곳"으로 알린다.
   - 시·도 본청(서울특별시, 경기도 등)은 시·군·구가 아니므로 시·도 이름 옆 마커로 표시.
   - 지도 색은 유효 계약에서 자동 계산. 따로 관리할 것 없음.

## 경계 자료 (2026-10-20 비교)

- **확정(2026-10-20)**: 자료는 **B**. 선 스타일은 `stage8-map-style.html`의 것 — 시·군·구 0.45px 연회색, 시·도 1px 회색, 둥근 모서리, 코너 깎기(Chaikin 2회)로 매끈하게, 확대해도 선 굵기 고정, 시·도 선은 시·군·구 선을 합쳐 생성(겹침·끊김 없음). 전국용/확대용 두 단계 상세도.
- 행정구역 표기: 현행 이름(강원특별자치도·전북특별자치도, 군위군은 대구). 광주광역시+전라남도는 고객사 분류와 맞춰 "전남광주통합특별시" 한 묶음으로 시·도 선을 그린다.

## 시안 2차 검토 → 3차 반영 항목 (2026-10-20)

사용자: 시·도 확대 시 주변은 비활성화해 그 시·도만 보이게 / 공기업 표시가 묶음 필터와 따로 놂(C만 있는 기관이 도청 보안 보기에서도 보임) / 확대하면 글자도 알맞게 바뀌어야.
검토(디자이너 관점) 추가: 전국 보기에서 서울·인천·경기 칩 겹침 / 터치에서는 말풍선이 없으니 탭=패널 / 파일 4.6MB는 구현 때 시·도별 분할 / 색약 대비로 묶음명 글자 병기·범례 전환 / "없음" 지역 패널 문구.

3차 반영(`stage8-map-mockup3.html`): ① 집중 모드(다른 시·도 흐리게·조작 차단, "전국 › 시·도 ×" 경로, 전국 복귀) ② 본청·공기업 배지·점·패널 목록·고객사 수가 묶음 필터를 따름 ③ 전국=시·도 칩, 시·도 집중=칩 숨기고 면 안에 시·군·구 이름(면이 충분할 때만), 글자 크기 화면 기준 고정 ④ 겹치는 칩은 위아래로 비켜 놓고 그래도 겹치면 납품 수 적은 쪽 숨김 ⑤ 범례 클릭으로 묶음 전환(다시 누르면 전체) ⑥ 없음 지역 패널 문구 "아직 납품이 없는 지역입니다".

## 3차 검토 보완 항목 결정 (2026-10-20, 하나씩 확인)

1. (확정) 수도권 확대 삽입 지도: 전국 보기에서 지도 오른쪽 위에 서울·인천·경기 확대 상자를 둔다.
2. (확정) "미납품만 강조" 전환: 켜면 납품 없는 시·군·구를 연한 강조색으로, 납품 지역은 옅게 뒤집어 보여준다. 묶음 필터와 함께 동작(도청 보안 미납품 등).
3. (확정) 면 색 — 사용자 지정: 둘 다 #0B1623(브랜드 네이비) / 도청 보안 #52A5DA / 불법촬영 #DF2E38. 없음은 #EEF1F5 유지. 범례·집계 막대·패널 색도 같은 값으로.
4. (확정) 패널의 기관을 누르면 납품현황의 고객사 상세로 이동(직원용 상세 링크). 새 탭이 아니라 같은 창.
5. (확정) 지도 아래 시·도별 카드 줄은 없애고, 패널 기본 화면(아무것도 선택 안 함)에 "시·도별 납품 비율" 순위를 보여준다. 누르면 그 시·도로 확대.
6. (확정) 마우스를 올리면 그 시·군·구 테두리를 진하게 띄우고, 말풍선이 커서 바로 옆(8px)에 붙어 따라다닌다. 1차에서 말풍선이 멀리 떨어져 보이던 문제를 고치고, 화면 가장자리에서는 반대쪽으로 뒤집는다. 커서 모양은 바꾸지 않는다.
7. (확정) 시·도 칩 한 번 탭 = 그 시·도로 확대 + 패널에 본청·공기업 목록. 더블클릭 동작은 없앤다.
8. (확정) 모바일 패널은 아래에서 올라오는 시트(반쯤/다 열림), 지도는 위에 고정. 1차에 포함.
   - 모바일에서 지도를 가리는 요소 정리(사용자 지적): 지도 위에는 집중 모드의 "← 전국" 버튼만 남긴다. 집계 카드는 시트의 접힌 손잡이 줄("납품 120/252 · 도청 104 · 불법촬영 28")로 옮기고, 범례는 조작 버튼 아래 한 줄의 작은 색점으로, +/− 확대 버튼은 터치 기기에서 숨김(두 손가락 확대), 경로 표시는 시트 머리로. 데스크톱은 지금처럼 지도 위 카드 유지.
9. (확정) 보기 상태(지자체/의회, 묶음, 미납품 강조, 집중 시·도, 선택 시·군·구)를 주소에 남겨 링크 공유·새로고침·뒤로 가기가 된다. 키보드: Esc(선택 해제 → 전국), +/−(확대·축소).
10. (확정) 소재지 추정 기관에 지도·패널 표시는 달지 않는다. 기획팀 고객사 관리 화면에서 "소재지 확인 필요" 목록으로만 관리하고, 입력 전에 11곳을 확인받는다.
11. (확정) 울릉군은 유지(확대 시 이름만), 독도는 1차 생략.
12. (확정) 시·도 칩은 약칭(서울·경기·충남·전남·광주 등), 패널·말풍선·경로 표시는 정식 명칭.
13. (확정) 경계 파일 분할: 전국용 가벼운 선(약 1MB) 먼저, 세밀한 선은 시·도별 파일로 나눠 그 시·도를 확대할 때만 불러온다.
14. (확정) 접근은 계정별로: 계정 관리 화면에 "지역 현황 열람" 켜기/끄기. 기본값 직원 켜짐·파트너 꺼짐. 파트너 계정을 켜면 지도는 공개 고객사만 칠하고 비공개는 색·목록·수 어디에도 넣지 않는다(파트너별로 다른 공개 범위를 만드는 것이 아니라 페이지 접근만 다름 — PRD 대조 시 이 해석을 명시).
   - 돌아가기(확정, 네 가지 모두): ① 집중 모드에서는 지도 왼쪽 위에 엄지로 누르기 쉬운 "← 전국" 버튼을 항상 띄움 ② 두 손가락/휠로 전국 크기보다 더 축소하면 자동으로 전국 보기로 복귀 ③ 브라우저 뒤로 가기도 전국으로(보기 상태를 주소에 남김 → 9번과 연결) ④ Esc.
   - 5번 빠져나오는 길(패널 안에서 한 단계씩): 패널 머리에 경로 "시·도별 현황 › 강원 › 춘천시"를 두고 앞 단계를 누르면 그 단계로 돌아간다. 패널의 × 는 선택 해제 → 기본 화면(순위). 지도의 빈 바다/배경을 누르거나 Esc를 눌러도 선택 해제. 지도의 "전국 ›" 경로와 패널 경로는 같은 상태를 가리키도록 연동(전국으로 돌아가면 패널도 순위 화면).
